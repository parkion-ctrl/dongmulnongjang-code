# 동물농장 리메이크 (쥬니버네이버 「동물농장」 모바일 재구현)

옛 쥬니버네이버 「동물농장」을 개인용으로 스마트폰에서 플레이할 수 있게 다시 만드는 프로젝트다.
이 문서는 다른 사람(또는 AI)이 작업을 이어받을 수 있게 현재 상태를 정리한 인수인계 문서다. (2026-10-05 기준)

- 플레이 주소: https://dongmulnongjang.pages.dev (Cloudflare Pages, 폰 브라우저에서 '홈 화면에 추가'로 앱처럼 사용)
- 형태: 서버 없는 정적 웹앱(PWA). `index.html` 한 파일에 화면·로직이 모두 들어 있다. 세이브는 브라우저 localStorage.

## 1. 원칙 (사용자가 정한 것)

- **원작 느낌이 최우선.** 원작 그래픽을 구할 수 있으면 새로 그리지 않고 원작을 쓴다. UI도 원작 그림·배치를 최대한 따른다.
- 다만 원작은 PC용이라 그대로 옮기면 불편하다. 버튼 크기·하단 메뉴·세로 스크롤 등은 폰에 맞게 바꾼다.
- 원작에 없는 그림(사람이 된 동물, 여행지 계절 풍경 등)만 AI로 만든다(OpenAI gpt-image-2, 원작 그림을 참고 이미지로 넣어서).
- 온라인 요소 없는 **솔로 패키지 게임**. 스토리를 보고, 동물을 키워서, 탑(던전)을 깨서 엔딩을 보는 구조.

## 2. 게임 설계 (확정)

- **메인 순환:** 동물 육성 → 엔딩(사람이 됨) → 탐험 동료로 합류 → 4인 파티로 탑 등반 → 특정 층에서 오리지널 스토리 개방.
- **원작 세계관:** 마녀의 실수로 몽게몽게왕국 사람들이 동물로 변했고, 잘 키워서 마법 주문을 찾으면 다시 사람이 된다(원작 설정 그대로).
- **성장(원작 기준):** 애정·매력·건강·지식지수가 *각각* 90 → 1차성장, 210 → 2차성장, 300 → 엔딩 도전. 지수 최대 1000.
- **엔딩 평가:** 지수 합계 + 히든 노력 점수(학교·여행·알바·수확제 등 잡활동, 아이템으로는 안 오름) × 2 → S/A/B/C. 엔딩 이후에도 동료를 강화할 수단이 필요(미정).
- **동료 규칙:** 파티 4명. 같은 종은 동료 1명만. 메인 스토리(탑) 엔딩 전에는 사람이 된 종을 다시 분양받을 수 없고, 엔딩 후엔 가능하지만 동료로 합류하지 않음. 크리스마스 버전은 별개 종(총 62종).
- **날짜(프린세스 메이커 2 느낌, 시간 압박 없음):** 3월 1주차 시작, 한 달 4주. 매주 돌봐주기 3번 + 일정 1개를 고르면 일주일이 지남. 고정 행사는 9월 4주차 끝의 수확제 하나. 계절은 여행 풍경 등 연출에만 쓴다.
- **피로·질병:** 피로 70↑ 효과 반감, 100 활동 불가. 주가 끝날 때 피로가 높을수록 병에 걸림(50↑ 8%, 70↑ 25%, 90↑ 45%). 병은 가벼움 → 보통 → 심함 → **중병** 순으로 매주 심해짐. 진료(20P)로 병명·단계·처방 확인, 같은 계열의 약을 단계 이상으로 먹이면 나음. 중병은 약 불가, 강제 입원(무료, 한 주 소모, 모든 지수 80% 감소, 성장 단계 하락 가능).
- **탐험(북쪽 탑, 원작 방식 기반 - 뼈대 구현됨):** 원작 탐험의 환산을 그대로 씀: 공격 = 애정/10, 방어 = 매력/10, 체력 = 건강, 마력 = 지식. 명령은 원작 3가지(공격하기·방어하기·마법공격) + 물약. 4인 파티가 같은 명령으로 함께 행동(폰에서 4명 따로 고르면 번거로워서). 30층, 10층마다 저장(저장 안 하고 나가거나 전멸하면 그동안 모은 포인트·아이템을 잃음 - 원작 규칙). 탐험은 날짜를 쓰지 않음.
- **미정:** 동료 추가 강화 수단(현재는 장비만), 오리지널 스토리 내용, 탑 정복을 '게임 엔딩'(gameCleared)으로 볼지, 원작 2장 '동굴'(몬스터 12종) 추가 여부.

## 3. 구현된 기능 (`index.html`)

| 메뉴 | 내용 |
|---|---|
| 키우기 | 원작 실내 돌보기 방(`bg_bring_skin.gif`), 원작 동물 GIF와 행동 시 바뀌는 자세(`_face1`), 지수·피로·질병 표시, 하고 싶은 놀이(원하는 놀이면 2배), 음식주기/씻겨주기/책 읽어주기, 이번 주 일정, 동물과 대화하기(키워드 대답 + 가르친 말), 엔딩 도전 |
| 꾸미기 | 실외 마당. 원작 배경 스킨 10종 위에 동물이 돌아다니고, 꾸미기 아이템을 끌어서 배치 |
| 아이템 | 원작 아이템박스 탭(음식/꾸미기/용품/약품). 음식 먹이기, 꾸미기 '농장에 놓기', 약 먹이기 |
| 마을 | 원작 마을 지도 + 시설 목록: 여행사, 쿠킹샵, 아이템 가게, 동물학교, 동물병원 (페스티발·장터·라즈벨의 수정구슬은 준비 중) |
| 탐험 | 북쪽 탑 30층 오르기(아래 참고), 동료 장비, 마법 상인 길데스텐, 몬스터 도감 |
| 수첩 | 동물수첩(만난 동물·단계), 동료 목록과 4인 파티 편성 |

시설별:
- **여행사:** 원작 여행지 6곳(고른 곳만 AI 컬러판으로 표시), 이동수단 4·숙소 4, 항상 4박 5일. 결과에 여행지 × 계절 AI 풍경(24장), 쿠킹 재료 기념품.
- **쿠킹샵:** 원작처럼 재료 2개 → 요리. Wayback 원작 요리 비법서 팝업 139개에서 복원한 요리법 53개·음식 108종. 비법서는 매주 1개 공개. '먹을 수 없는 요리'는 먹일 수 없고 아이템에 남음(나중에 연금술 재료).
- **아이템 가게:** 원작 꾸미기 아이템 48종(이름·가격 임시).
- **동물학교:** 원작 버튼 4개. 수업하기(퀴즈 3문제, 새로 작성), 색칠하기(원작 도안 46장에 칠하기), 소설책방(이야기 5편, 새로 작성), 말 가르치기(대화창에서 따라 함).
- **동물병원:** 원작 진료실/약국/입원실. 원작 약 6계열 × 3단계.
- **탐험(북쪽 탑):** 원작 몬스터 7종의 도감 수치 그대로(거대 박쥐 15/5/60 … 사신 200/70/600, 암흑의 마도사 500/130/1000). 층 구성: 1~4 박쥐, 5~9 좀비, 10~14 죽음의 늑대, 15~19 드라큘라, 20 사신(보스), 21~29 왕거미, 30 마도사(보스). 같은 구간에서는 층마다 10%씩 강해짐. 보스는 3턴마다 전체 공격. 1층과 10·20·30층을 뺀 층은 문 두 개 중 하나를 고르는 갈림길(가끔 문 뒤가 안 보임): 몬스터 / 강한 몬스터(성난 ○○, 보상 많음) / 보물상자(열려고 하면 20%는 함정 상자 - 퍼즐 없이 독가스로 모두 체력 -15%, 80%는 자물쇠 퍼즐 3종 중 하나: 길 잇기 4·5·6칸 / 보석 밝히기 3·4·5칸 / 연동 원판 3·4·5개, 10층·20층마다 커짐, 시간 제한 없음, 포기 가능, 풀면 30+층×4 P·70% 물약·15층부터 15% 황금덩어리) / 회복의 샘 / 함정 복도(지식 또는 건강으로 통과 판정) / 떠돌이 상인 / 원작 '퀴즈 지배인'의 넌센스 퀴즈 / 도움 요청.
- **전투 연출:** 한 턴의 결과를 순서대로 보여 줌: 공격 = 흰 베기 + 피해 숫자 + 몬스터 흔들림, 마법 = 불꽃 터짐(노란 숫자), 몬스터 공격 = 앞으로 튀어나옴 + 맞은 동료 칸 붉게 흔들림, 보스 전체 공격 = 화면 붉은 번쩍임, 방어 = 파란 보호막, 물약 = 초록 반짝임 + 회복 숫자, 체력 막대는 줄어드는 모습이 보임. 연출 중에는 명령 버튼이 잠김. '동작 줄이기' 설정이면 거의 생략.
- **도움 요청(사용자 설계):** 파티에 없는 동물 하나가 게스트로 나와 셋 중 하나를 부탁. 길 찾기 = 무작위 미로를 제한 시간 안에 출구까지(층이 높을수록 커짐, 밀기·화살표·키보드), 물자 = 물약 1개, 몬스터 퇴치 = 그 층 잡몹 2마리 동시 전투(눌러서 대상 선택). 성공하면 90% 보상(500P / 무구 1개 / 정령의 기운 / 신의 직물 / 튼튼한 목재 중 하나), 10%는 위장한 유령의 장난(-200P / 물약 2개 도난 / 3층 동안 능력치 -20% / 5층 후퇴 / 장착 장비 하나 이번 탐험 동안 봉인 중 하나). 신의 직물·튼튼한 목재는 원작 아이템 그림, 정령의 기운·유령은 AI. 방 배경 장면 7장과 암흑의 마도사 그림(원작은 '?' 실루엣뿐)은 AI(`research/gen_explore.py`), 퀴즈 자매·봉인된 문은 원작 그림. 30층 앞은 원작 팁의 주문 「익스 피니트 릭투」로 여는 봉인된 문. 10·20·30층을 처음 깨면 보너스 장비와 이야기(자리만 있음). 드롭: 황금덩어리·마법의 정령(원작 연금술 설명대로 강한 몬스터에게서) → 아이템박스 '용품' 탭. 장비는 원작 탐험 아이템 그림(`item/game_*.gif`: 나무·기사·번개 검, 엑스칼리버, 나무·철·크리스탈·무지개 방패, 체력/마력 회복 약). 시뮬레이션 기준: 엔딩 최저(지수 300) 파티는 25층 근처, 지수 500 + 철 장비면 정복.
- **욕설 필터:** 이름·대화·말 가르치기에 적용(메이플 수준, 초성·숫자 섞은 변형 포함, 젖소·시바견 등 예외).

**임시 값:** 지수 상승량, 가격, 질병 확률, 등급 기준, 아이템·약 일부 이름 등 숫자 대부분. 원작 수치 자료는 못 찾음.

## 6. 개발·배포

- 로컬 실행: 저장소 폴더에서 `python -m http.server` 후 브라우저로 `index.html`.
- 테스트: `pip install playwright` 후 `python tests/test_ui.py` 등. 각 테스트가 임시 서버를 띄워 폰 크기로 돌림. 개발자 도구 대신 세이브(localStorage `dongmulnongjang.save.v1`)를 직접 고쳐 상황을 만든다.
- 배포: `python research/deploy.py` → `research/build_dist.py`가 `dist/`를 만들고(그림 묶음 `assets/sprites_bundle.js` 생성, 버전 붙이기) wrangler로 Cloudflare Pages(`dongmulnongjang`)에 올림. 필요: 게임 폴더 `.env`의 `CLOUDFLARE_API_TOKEN`, `CLOUDFLARE_ACCOUNT_ID`.
- AI 그림 생성: `research/gen_humans.py`, `research/gen_travel.py`, `research/gen_explore.py` (`.env`의 `OPENAI_API_KEY`).
- `.env`, `dist/`, `archive_original/`, `assets/sprites_bundle.js`는 저장소에 넣지 않는다.
